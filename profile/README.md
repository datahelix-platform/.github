# DataHelix

DataHelix is a modular, open-source platform for structured scientific data: a LinkML-driven
domain graph, the tools to explore and narrate it, and the deployment recipes that compose them.
It is developed by Adam Labadorf with the National Center for PTSD Brain Bank, U.S. Department of
Veterans Affairs.

## Repositories

| Repository | What it is |
|---|---|
| [datahelix](https://github.com/datahelix-platform/datahelix) | The platform umbrella: documentation, cross-component certification, deployment recipes, and submodules for each component. Start here. |
| [mosaic](https://github.com/datahelix-platform/mosaic) | LinkML runtime: the schema-driven entity service with provenance, validation, and pluggable storage. |
| [aperture](https://github.com/datahelix-platform/aperture) | AI-native data and workflow explorer, driven by configuration. |
| [reel](https://github.com/datahelix-platform/reel) | Headless data-story engine that composes query states into replayable stories. |
| [linkml-modeler-app](https://github.com/datahelix-platform/linkml-modeler-app) | Visual editor for LinkML schemas. |
| [linkml-data-gen](https://github.com/datahelix-platform/linkml-data-gen) | Stochastic, schema-valid test-data generator for any LinkML schema. |

Documentation: https://datahelix-platform.github.io/datahelix/
